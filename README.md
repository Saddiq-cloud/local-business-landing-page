## Project Overview

LUXEWEAR GH is a single-page clothing store landing page designed to present a modern African fashion brand online.

The website is designed for young adults and fashion-conscious customers looking for modern, affordable clothing with African-inspired style.

The main goal of the website is to introduce the brand, showcase its fashion collection, explain how customers can engage with the store, and provide a simple way for visitors to make an enquiry.

## Visual Direction

The website uses a premium and minimalist fashion direction.

### Main Colours

- Warm Ash: `#F7F5F0`
- Charcoal: `#171717`
- Gold: `#C9A227`
- White: `#FFFFFF`
- Muted Gray: `#6B6B6B`

The gold accent is used to create a refined fashion feel while the warm ash and charcoal provide contrast and readability.

## JavaScript Interaction

The Contact Us form includes a JavaScript interaction.

When a visitor submits the form:

1. The page does not reload.
2. JavaScript reads the visitor's name.
3. A personalized confirmation message is displayed.
4.The contact enquiry form is a frontend-only demo and does not send actual messages.
5. The form is automatically cleared.

Example:

> Thank you, Saddiq! Your enquiry has been received. We'll get back to you soon.

---

## Responsive Design

The website was designed to work on both laptop and mobile screen sizes.

Responsive CSS media queries were used to:

- Stack content on smaller screens
- Adjust navigation
- Resize headings
- Make service cards responsive
- Make the fashion gallery responsive
- Keep the contact form within the screen

The website was tested using a mobile viewport and displayed correctly.
